# Численные методы

Какие алгоритмы обучения работают быстрее? Научимся находить их вычислительную сложность (англ. сomputational complexity).

Сколько времени на выполнение операций тратят компьютеры, зависит от их мощности: у всех оно разное. Поэтому время работы алгоритма (англ. algorithm running time) не измеряют в секундах. Оно определяется количеством выполняемых алгоритмом элементарных операций: сложений, умножений и сравнений.

Когда говорят о времени работы на определённом компьютере, обычно его называют реальным временем работы (англ. real running time). Можно встретить понятие — wall-clock time (англ. «время настенных часов»), то есть время работы алгоритма определяется не процессорным временем, а временем на часах.

На время работы алгоритма также влияют его аргументы. Например, чтобы найти число в списках разной длины (10 и 1000), и операций нужно разное количество.

Посчитаем время работы алгоритма, который все значения списка увеличивает на единицу. Обозначим длину списка n. Время работы — это функция от n, то есть T(n) (от англ. time).

```python
# англ. увеличивать

def increase(elements):
    n = len(elements)

    for i in range(n):
        elements[i] += 1
```

Будем считать, что:

- На вызов функции len() или range() уходит одна операция;

- Присваивание со сложением +=, обычное присваивание = или обращение по индексу выполняется за одну операцию;

- Каждый шаг цикла — это две операции: нужно не только увеличить i на единицу, но и проверить, не превышено ли количество элементов в списке.

```python
def increase(elements):
    n = len(elements)     # 2 операции

    for i in range(n):    # 1 операция + 2 операции * n
        elements[i] += 1  # 2 операции (для каждого значения i)
```

T(n) получим так: 2 + 1 + n * (2 + 2) = 4n + 3 (одночлены записываются в порядке убывания степени).

Время работы сложных алгоритмов вычислить нельзя. Поэтому рассчитывают их вычислительную сложность, или асимптотическое время работы (англ. asymptotic running time) — от слова асимптота (от др.-греч. ἀσύμπτωτος, «несовпадающий»). Так называется прямая, к которой кривая приближается, но не может её пересечь.

Асимптотическое время работы алгоритма показывает, как растёт T(n) при увеличении n.

Когда T(n) — это многочлен (сумма одночленов, т. е. произведений чисел и переменных разных степеней), то асимптотическое время работы равно одночлену наибольшей степени без коэффициента (например, n² вместо 5n²). При больших значениях n остальные одночлены не важны.

Рассмотрим примеры:

- Если T(n) = 4n + 3, асимптотическое время работы T(n) ~ n. У алгоритма линейная сложность (англ. linear complexity). Знак тильда (~) означает, что асимптотическое время работы равно n.

- Если T(n) = 5n² + 3n - 1, асимптотическое время работы T(n) ~ n². У алгоритма квадратичная сложность (англ. quadratic complexity).

- Если T(n) = 10n³ - 2n² + 5, то T(n) ~ n³. У алгоритма кубическая сложность (англ. cubic complexity).

- Если T(n) = 10, то T(n) ~ 1. У алгоритма константная сложность (англ. constant complexity), то есть не зависит от n.

## Время обучения линейной регрессии

![Рост T(n): константа, линейная, квадратичная и кубическая сложность](figures/nm-complexity.png)

Задача обучения линейной регрессии такая:

$$

w=\arg\min  MSE(Xw,y)

$$

Веса вычисляются по формуле:

$$

w=(X^{T} \cdot X)^{-1} \cdot X^{T} \cdot y

$$

Найдём вычислительную сложность расчёта весов, но прежде:

- Обозначим количество объектов в обучающей выборке как n, а количество признаков — p;

- Размер матрицы X будет n x p, размер вектора y — n;

- Обозначим вычислительную сложность как T(n, p), поскольку она зависит от двух параметров: n и p.

Чтобы рассчитать сложность обучения алгоритма, сложим ответы:

$$

T(n, p) \sim np^{2} + p^{3} + np^{2} + np

$$

Признаков обычно меньше, чем объектов, то есть p < n. Умножим обе части на p², получим p³ < np². Оставим только одночлен наибольшей степени и получим: T(n, p) ~ np². Если признаков много, модель будет обучаться долго.

## Итеративные методы

Можно ли обучить линейную регрессию быстрее? В этом помогут итеративные методы.

Задача решается прямым методом (англ. direct method), когда модель линейной регрессии обучается по такой формуле:

$$

w=(X^{T} \cdot X)^{-1} \cdot X^{T} \cdot y

$$

Прямые методы помогают найти точное решение по заданной формуле или алгоритму. Их вычислительная сложность не зависит от данных. Даже если в выборке все ответы и искомые веса равны нулю, алгоритм всё равно проделает все матричные умножения для поиска решения.

**Другой подход к обучению модели линейной регрессии** — итеративный метод, или итеративный алгоритм (англ. iterative method; iterative algorithm).

Он не даёт точного решения, только приближённое. Название метода произошло от латинского слова iteratio («повторение»). Алгоритм многократно выполняет похожие итерации, на каждом шаге решение становится всё точнее. Если слишком большая точность не нужна, хватит и небольшого числа итераций.

Вычислительная сложность итеративных методов зависит от числа шагов, на которое может влиять и содержание данных.

## Метод бисекции

![Метод бисекции: деление отрезка пополам](figures/nm-bisection.png)

**Итеративным методом найдём решение уравнения f(x)=0. Пусть f(x)** — непрерывная функция (англ. continuous function). То есть график такой функции можно нарисовать, не отрывая карандаша от бумаги.

Решить уравнение поможет метод бисекции (англ. bisection method, «делить пополам»). На вход он принимает непрерывную функцию и отрезок [a,b]. У значений f(a) и f(b) разные знаки.

Когда выполняются два условия:

функция непрерывна,

у значений на концах отрезка разные знаки,

то корень уравнения где-то на отрезке.

На каждой итерации метод бисекции:

Проверяет, равно ли нулю любое значение f(a) или f(b). Если равно, то решение найдено;

Находит середину отрезка c=(a+b)/2;

Сравнивает знак f(c) со знаками f(a) и f(b):

- Если у f(c) и f(a) разные знаки, то корень обязательно есть на отрезке [a,c]. К этому отрезку и переходит алгоритм на следующей итерации;

- Если у f(c) и f(b) разные знаки, то корень обязательно есть на отрезке [c,b]. К нему переходит алгоритм на следующей итерации;

Знаки f(a) и f(b) разные, поэтому других вариантов быть не может.

Обычно заранее выбирают точность решения, например, e=0.000001 (от error, «ошибка»). На каждой итерации отрезок с корнем уменьшается в два раза. Если длина отрезка получается меньше e, работу алгоритма можно остановить. Такое условие называется условием остановки (англ. stopping criterion).

Допишите код функции bisect(), которая методом бисекции найдёт решение уравнения. На вход она принимает:

- function — функция с искомыми нулевыми значениями. В Python аргументами можно передавать функции. А вызывают её так: function(x);

- left, right — левый и правый концы отрезка;

- error — допустимая величина ошибки (от неё зависит точность алгоритма).

```python
import math

def bisect(function, left, right, error):
    while right - left > error:

        # проверяем, нет ли нулей

        if function(left) == 0:
            return left

        if function(right) == 0:
            return right

        # середина отрезка
        middle = (left + right) / 2

        # выбираем нужную половину

        if function(left) * function(middle) < 0:
            right = middle
        else:
            left = middle
    return left

def f1(x):
    return x**3 - x**2 - 2*x

def f2(x):
    return (x+1)*math.log10(x) - x**0.75
print(bisect(f1, 1, 4, 0.000001))
print(bisect(f2, 1, 4, 0.000001))
```

## Сравнение методов

Корни уравнения можно найти и напрямую. Какой метод выбрать?

Для функции f(x) = x³ - x² - 2x уравнение решается так:

Выносим x за скобки: (x² - x - 2)x = 0; ноль — первый корень уравнения.

Дискриминант квадратного уравнения (x² - x - 2) равен 1 + 4*1*2 = 9.

Дискриминантом (от лат. discrimino, «различаю»; D) квадратного уравнения

ax² + bx + c = 0 называют выражение b² - 4ac. Если D > 0, у квадратного уравнения два корня;

D = 0, то корень один; D < 0, действительных корней нет.

Корни уравнения (x² - x - 2) вычисляются по формуле (-b ± √D)/2a),

т. е. (1 ± 3)/2.

Получаем такие корни: -1, 0, 2.

Посчитали быстро: даже код не пришлось запускать.

Сделать то же самое с функцией f(x) = (x+1)*math.log10(x) - x**0.75 не выйдет. Напрямую найти корень для неё нельзя. А вот методу бисекции неважно, с какой функцией работать. Главное — она должна быть непрерывной.

Бóльшая часть этого курса посвящена ключевому для машинного обучения итеративному методу — градиентному спуску (англ. gradient descent). На нём построено много алгоритмов обучения.

Обозначим его преимущества перед прямыми методами:

- Для линейной регрессии с функцией потерь MSE он работает быстрее на больших наборах данных.

- Градиентный спуск годится для линейной регрессии и с другими функциями потерь (не для всех есть формулы).

- Он применим в обучении нейронных сетей, для которых тоже нет прямой формулы.

## Минимизация функции потерь

Чтобы сформулировать задачу для градиентного спуска, рассмотрим задачу обучения по-новому.

Вы уже знаете, что существуют метрики, которые оценивают качество модели. Для похожих задач также используют функцию потерь. Метрика качества оценивает модель на тестовой выборке, и в отличие от неё функция потерь показывает, насколько хорошо модель выполняет задачу обучения на конкретных данных.

Функция потерь позволяет обновить параметры модели, чтобы минимизировать её ошибку на обучающих данных. Обозначим функцию потерь как L(y, a) (от англ. loss — «потеря»), где вектор y — правильные ответы, вектор a — предсказания.

Теперь запишем задачу обучения модели через минимизацию функции потерь:

$$

w=\arg\min  L(y,a)

$$

Чтобы вычислить MSE, или квадратичную функцию потерь (англ. quadratic loss function), разность между правильными ответами и предсказаниями возводится в квадрат:

$$

L(y,a)=sum^{n}_(i=1)(a_i-y_i)^{2}

$$

Какие ещё бывают функции потерь для задачи регрессии? Если в задаче важно, чтобы функция была менее чувствительна к выбросам, в отличие от MSE, применяют абсолютную функцию потерь (англ. absolute loss function), или знакомую вам MAE. Как и MSE, мы её рассматриваем как функцию потерь, а не как метрику качества.

$$

L(y,a)=sum^{n}_(i=1)|a_i-y_i|

$$

В задаче классификации часто применяют метрику качества accuracy. В редких случаях она подойдёт в качестве функции потерь. Всё потому, что у функции вычисления accuracy нет производной (англ. derivative), которая показывает изменение функции при небольших изменениях аргумента.

Заменим accuracy отрицательным логарифмическим правдоподобием (англ. negative logarithmic likelihood), или логистической функцией потерь (англ. logistic loss function). Функция потерь суммирует логарифмы вероятностей в зависимости от объекта. Если правильный ответ равен единице, прибавляется log₁₀ aᵢ, а если нулю — то log₁₀ (1 - aᵢ). Логарифм (от др.-греч. λόγος, «слово»; ἀριθμός, «число») — степень, в которую для извлечения аргумента нужно возвести основание (в нашем случае 10).

| L(y,a)=-sum^n_(i=1) | { | log_(10)a_i, |  | если y_i=1 |
| --- | --- | --- | --- | --- |
|  |  |  | { | log_(10)(1-a_i), |

**где aᵢ** — вероятность класса 1 для объекта с индексом i. То есть значение aᵢ должно быть как можно выше у объекта положительного класса и ниже — у объекта отрицательного класса.

Название отрицательного логарифмического правдоподобия произошло от функции правдоподобия. Она вычисляет, с какой вероятностью модель ответит на все объекты правильно, если для ответа возьмёт значения aᵢ:

| Likelihood(y,a)=П^n_(i=1) | { | a_i, | если y_i=1 |
| --- | --- | --- | --- |
|  |  |  |  |

Логарифмирование, то есть вычисление логарифма, применяется, чтобы «растянуть» значения на бо́льший диапазон. Например, он был от 0 до 1, а стал от -∞ до 0. В таком диапазоне погрешности вычислений не важны. А умножение на -1 нужно, потому что итоговая функция потерь должна быть минимизирована.

В отличие от accuracy, логистическая функция потерь имеет производную.

По формуле найдите значение логистической функции потерь при таких значениях y и a:

```python
y=(0,0,1,1,0)
a=(0.2,0.4,0.6,0.8,0.1)

from math import log10

print(-(log10(1 - 0.2) + log10(1 - 0.4) + log10(0.6) + log10(0.8) + log10(1 - 0.1)))
```

## Градиент функции

Минимум функции потерь не всегда можно найти вручную. Разобраться, в каком он направлении, поможет градиент функции (англ. function gradient).

Функция потерь зависит от параметров алгоритма. Это скалярная функция векторного аргумента, то есть она принимает на вход вектор, а возвращает скаляр.

**Градиент векторной функции** — это вектор, состоящий из производных ответа по каждому аргументу. Градиент на письме часто обозначают символом ∇, который называется оператор набла.

Градиент функции f от n-мерного вектора x вычисляется так:

$$

\nablaf(x)=(∂f/∂x_1,∂f/∂x_2,...,∂f/∂x_n)

$$

где ∂f/∂$x_i$ — производная функции f по аргументу x^i.

**Градиент функции от одного аргумента** — это производная:

$$

f(x)=(x−5)^{2}

$$

$$

\nablaf(x)=\nabla(x^{2}−10x+25)=2x−10

$$

Найдём градиент функции с тремя аргументами:

$$

f(x,y,z)=x^{2}+2y^{2}+10yz−5z

$$

Рассчитаем производные по

$$

∂f(x,y,z)/∂x=∂(x^{2})/∂x+∂(2y^{2})/∂x+∂(10yz)/∂x-∂(5z)/∂x=2x+0+0+0

$$

∂f(x,y,z)/∂y=0+4y+10z+0

∂f(x,y,z)/∂z=0+0+10y−5

Получаем трёхмерный вектор из производных:

$$

\nablaf(x,y,z)=(2x,4y+10z,10y−5)

$$

Для одномерной функции f(x)=(x−5)^2 антиградиент равен −∇f(x)=−2(x−5). Значения полученной производной антиградиента, которые стоят слева от точки x=5, положительные, а справа от неё — отрицательные.

Для функции f(x,y)=2x^2+2y^2−8 антиградиент равен −∇f(x)=(−4x,−4y). Посмотрите на его направление в каждой точке.

## Градиентный спуск

![Шаги градиентного спуска к минимуму](figures/nm-gd.png)

Найдём минимум функции потерь алгоритмом градиентного спуска.

**Градиентный спуск (англ. gradient descent)** — это итеративный алгоритм поиска минимума функции потерь. Он движется по направлению антиградиента и постепенно приближается к минимуму.

Градиентный спуск можно сравнить с глубоководным погружением. Если начинающий дайвер не изучил дайв-спот, одно резкое движение — и он может наткнуться на скалу. Поэтому погружаться надо медленно, рассчитывая каждый шаг.

Алгоритм градиентного спуска работает так же: «погружается на дно», многократно выполняя однотипные шаги. Добраться до минимума за одну итерацию сложно, ведь вектор антиградиента показывает направление убывания, а не конкретную точку минимума функции потерь.

Чтобы приступить к спуску, выберем отправное значение аргумента — вектора x. Оно называется начальным значением (англ. initial value) и обозначается x⁰.

С него будет сделан первый шаг градиентного спуска (англ. gradient descent step). Следующая точка x¹ образуется так: к точке x⁰ прибавляется антиградиент (вычитается градиент), умноженный на размер шага градиентного спуска $\mu$.

$$

x¹=x⁰-\mu \cdot \nablaf(x⁰)

$$

Значение $\mu$ контролирует размер шагов градиентного спуска. Если шаг маленький, понадобится много итераций, но каждая приблизит вас к минимуму функции потерь. Когда шаг слишком большой, то минимум можно просто пропустить.

По аналогичной формуле получим значения аргументов и на последующих итерациях. Номер итерации обозначим t. Чтобы получить новые значения xᵗ, к предыдущей точке прибавим антиградиент, умноженный на размер шага:

$$

xᵗ=x^{t-1}-\mu \cdot \nablaf(x^{t-1})

$$

Градиентный спуск завершается, когда выполнено хоть одно из этих условий:

- алгоритм прошёл заданное количество итераций,

- значение аргумента x перестало меняться.

1. Мы записали функцию f, в коде назвали её func(). Напишите функцию gradient(), которая по формуле вычисляет её градиент. Проверьте эту функцию на нескольких векторах.

2. Напишите функцию gradient_descent(), реализующую алгоритм градиентного спуска для функции f(x). На вход она принимает:

- initialization — начальное значение вектора x;

- step_size — размер шага $\mu$;

- iterations — количество итераций.

Функция возвращает значение вектора x после заданного числа итераций. Проверьте функцию на разных количествах итераций.

```python
import numpy as np

def func(x):
    return (x[0] + x[1] - 1)**2 + (x[0] - x[1] - 2)**2

def gradient(x):
    return np.array([4 * x[0] - 6, 4 * x[1] + 2])

def gradient_descent(initialization, step_size, iterations):
    x = initialization.copy()

    for _ in range(iterations):
        x = x - step_size * gradient(x)
    return x
print(gradient_descent(np.array([0, 0]), 0.1, 5))
print(gradient_descent(np.array([0, 0]), 0.1, 100))
```

## Градиентный спуск для линейной регрессии

Вернёмся к линейной регрессии и обучим её градиентным спуском.

Повторим задачу обучения линейной регрессии:

$$

w=\arg\min  MSE(Xw,y)

$$

Обучим модель градиентным спуском. Но прежде запишем функцию потерь в векторном виде, чтобы найти её градиент. Представим MSE как скалярное произведение разности векторов на себя:

$$

MSE(y,a)=1/n \cdot sum^{n}_(i=1)(a_i-y_i)^{2}=1/n(a-y,a-y)

$$

**где y** — вектор правильного ответа, a — вектор предсказания.

Преобразуем скалярное произведение в матричное:

$$

(a-y,a-y)=(a-y)^{T}(a-y)

$$

После транспонирования вектора, то есть его преобразования из столбца в строку, возможно  умножение на другой вектор.

Объединим формулы MSE и линейной регрессии:

$$

MSE(Xw,y)=1/n(Xw-y)^{T}(Xw-y)

$$

Найдём градиент функции по вектору параметров w. Градиенты векторных функций вычисляются, как и производные. Например, когда работаем с числами, производная (xw - y)² по вектору параметров w равна 2x(xw - y). Когда с векторами — от содержимого первой скобки остаётся только множитель при w, то есть Xᵀ:

$$

\nablaMSE(Xw,y)=2/n \cdot X^{T}(Xw-y)

$$

В формуле X.T.dot(X.dot(w) - y) две долгие операции:

1. Умножение матрицы X на вектор w. Оно выполняется за время np: для каждого n объекта считается скалярное произведение p-мерных векторов.

2. Умножение матрицы Xᵀ на вектор (Xw - y). Выполняется за время np: для каждого p признака вычисляется скалярное произведение n-мерных векторов.

Получаем T(n, p) ~ np.

Сложность решения прямым методом равна np². Одна итерация градиентного спуска в p раз быстрее. Вот только итераций может понадобиться больше p!

## Стохастический градиентный спуск

![Пакетный и стохастический градиентный спуск](figures/nm-sgd.png)

Чтобы сделать алгоритм обучения быстрее, уменьшим время одной итерации.

Время работы алгоритма уменьшится, если градиент вычислять на небольших частях обучающей выборки, которые называются мини-батчами, или батчами (англ. batch, «пачка»).  А чтобы алгоритм всё-таки «увидел» полную обучающую выборку, её батчи на каждой итерации должны меняться случайным образом.

За такое обучение отвечает стохастический градиентный спуск по мини-батчам, или стохастический градиентный спуск (от греч. στοχαστικός, «умеющий угадывать»; англ. stochastic gradient descent, SGD). Он помогает ускорить обучение модели.

Чтобы получить батчи, нужно перемешать все данные выборки и разбить её на части. В одном батче должно быть в среднем 100-200 объектов — это и есть размер батча (англ. batch size). Когда алгоритм SGD прошёл один раз по всем батчам, значит, завершилась одна эпоха (англ. epoch). Сколько всего будет эпох, зависит от размера обучающей выборки: одна-две эпохи — если выборка большая, несколько десятков — если маленькая. Количество батчей равно числу итераций для завершения одной эпохи.

Алгоритм стохастического градиентного спуска работает так:

1 На вход поступают гиперпараметры: размер батча, количество эпох и величина шага.

2 Определяются начальные значения весов модели.

3 Для каждой эпохи обучающая выборка разбивается на батчи.

4 Для каждого батча:

4.1. Вычисляется градиент функции потерь;

4.2. Обновляются веса модели (к текущим значениям весов прибавляется антиградиент, умноженный на величину шага).

5 Алгоритм возвращает последние веса модели.

Найдём вычислительную сложность SGD. Обозначим:

n — количество объектов во всей обучающей выборке;

b — размер батча;

p — количество признаков.

Чему равна вычислительная сложность выполнения шага для одного батча?

- T(n, b, p) ~ bp

Равна вычислительной сложности шага на всей выборке. Только объектов намного меньше.

Чему равна вычислительная сложность выполнения одной эпохи, если выборка на батчи делится нацело, то есть n/b — целое число:

- T(n, b, p) ~ np

**Точно! В одной эпохе n/b итераций, сложность каждой** — bp. Решение такое: n/b * bp = np.

Алгоритмом SGD линейная регрессия обучается быстрее, чем прямым методом.

1.Разработку алгоритма SGD начните с заглушки.

Добавьте в модель гиперпараметры epochs и batch_size. Соблюдая порядок, добавьте их в инициализатор класса и сохраните в атрибутах self.epochs и self.batch_size.

В функции fit() задайте, что начальные веса w равны нулям.

В функции predict() напишите формулу для вычисления предсказания.

Функция print() выведет значения метрики R2 на экран.

2.Добавьте циклы по эпохам и батчам, учитывая шаг по антиградиенту.

Вам нужно:

- вычислить количество батчей,

- найти градиент по батчу,

- сделать для весов шаг по антиградиенту.

Функция print() выведет значения метрики R2 на экран.

Добавьте в модель регуляризацию.

Допишите код регуляризации:

- приравняйте элемент с индексом ноль в векторе reg к нулю (обычно сдвиг не включается в регуляризацию);

- к градиенту функции прибавьте слагаемое для регуляризации.

В код модели из прошлой задачи мы добавили:

- новый гиперпараметр — вес регуляризации (reg_weight);

- обучение и тестирование с разными значениями.

На экране должны появиться значения весов регуляризации и метрики R2.

```python
import numpy as np
import pandas as pd
from sklearn.metrics import r2_score

data_train = pd.read_csv('/datasets/train_data_n.csv')
features_train = data_train.drop(['target'], axis=1)
target_train = data_train['target']
data_test = pd.read_csv('/datasets/test_data_n.csv')
features_test = data_test.drop(['target'], axis=1)
target_test = data_test['target']

class SGDLinearRegression:
    def __init__(self, step_size, epochs, batch_size, reg_weight):
        self.step_size = step_size
        self.epochs = epochs
        self.batch_size = batch_size
        self.reg_weight = reg_weight

    def fit(self, train_features, train_target):
        X = np.concatenate((np.ones((train_features.shape[0], 1)), train_features), axis=1)
        y = train_target
        w = np.zeros(X.shape[1])

        for _ in range(self.epochs):
            batches_count = X.shape[0] // self.batch_size

            for i in range(batches_count):
                begin = i * self.batch_size
                end = (i + 1) * self.batch_size
                X_batch = X[begin:end, :]
                y_batch = y[begin:end]
                gradient = 2 * X_batch.T.dot(X_batch.dot(w) - y_batch) / X_batch.shape[0]
                reg = 2 * w.copy()
                reg[0] = 0
                gradient += self.reg_weight * reg
                w -= self.step_size * gradient
        self.w = w[1:]
        self.w0 = w[0]

    def predict(self, test_features):
        return test_features.dot(self.w) + self.w0

# проверки

for reg in [0.0, 0.1, 1.0, 10.0]:
    print("Регуляризация:", reg)
    model = SGDLinearRegression(0.01, 10, 100, reg)
    model.fit(features_train, target_train)
    pred_train = model.predict(features_train)
    pred_test = model.predict(features_test)
    print(r2_score(target_train, pred_train).round(5))
    print(r2_score(target_test, pred_test).round(5))
```

## Основы нейронных сетей

Алгоритмом SGD обучается не только линейная регрессия, но и нейронная сеть. Разберёмся, как она устроена и как обучается.

**Нейронная сеть (англ. neural network)** — это модель, которая состоит из множества простых моделей, например, линейных регрессий. Название пришло из биологии: искусственная нейронная сеть работает по принципу сетей нервных клеток, то есть из нейронов строит сложные зависимости между входными и выходными данными.

Значение на каждом выходе, или нейрон, вычисляется так же, как и предсказание линейной регрессии:

```python
a_1=xw_1
a2+xw_2
```

**У каждого значения выхода** — свои веса (w₁ и w₂).

Рассмотрим другую нейронную сеть. В ней три входа x₁, x₂, x₃, две промежуточных переменных h₁ и h₂ (англ. hidden) и один выход а.

Значения h₁ и h₂ передаются в логистическую функцию $\sigma$(x):

$$

\sigma(x)=1/(1+e^{-x})

$$

**где e** — число Эйлера; приблизительно равно 2.718281828.

**Логистическая функция в нейронной сети** — это функция активации (англ. activation function). Она добавляется в нейрон после умножения значений входов на веса, когда выходы нейрона становятся входами для других нейронов. Такими нейронами можно описать более сложные зависимости.

**Промежуточная переменная (h₁, h₂)** — это произведение значения входа на вес:

```python
h_1=xw_1
h_2=xw_2
```

Для удобства промежуточные переменные h₁ и h₂ обозначим вектором h. Предсказание нейронной сети вычисляется по формуле:

```python
a=σ(h)w_3
```

Запишем эту формулу через векторную функцию. Веса w₁ и w₂ обозначим столбцами матрицы W. Получим такую векторную формулу:

```python
a=σ(xW)w_3
```

Если в матрицы записать веса нескольких нейронов, можно получить ещё более сложную сеть.

где:

x — входной вектор размерностью p (количество признаков);

**W₁** — матрица размерностью p x m;

**W₂** — матрица размерностью m x k;

**W₃** — матрица размерностью k x 1;

a — предсказание модели (одно число).

Когда такая нейронная сеть рассчитывает предсказание, она последовательно выполняет все операции:

```python
a=σ(σ(xW_1)W_2)W_3
```

## Обучение нейронных сетей

Чтобы обучить нейронную сеть, нужно сформулировать задачу обучения.

Любую нейронную сеть можно записать функцией от её входного вектора и параметров. Обозначим:

- X — признаки обучающей выборки;

- P — набор всех параметров нейронной сети;

- N(X, P) — функция нейронной сети.

**Параметры нейронной сети** — это веса в нейронах:

$$

P=W_1,W_2,W_3

$$

Функция нейронной сети такая:

```python
N(X,P)=σ(σ(XW_1)W_2)W_3
```

Также обозначим:

- y — ответы обучающей выборки;

- L(a, y) — функция потерь (например, MSE).

Тогда задача обучения нейронной сети формулируется так:

min L(N(X,P),y)

Минимум этой функции также находится алгоритмом SGD.

Алгоритм обучения нейронной сети такой же, как и алгоритм SGD для линейной регрессии. Только вместо градиента для линейной регрессии вычисляется градиент для нейронной сети:

$$

\nablaL(N(X,P),y)

$$

## Ансамбли и бустинг

**Ансамбль** — набор моделей для решения одной и той же задачи. Сила ансамблей в том, что вместе модели ошибаются в среднем не так сильно, как по отдельности.

**Один из подходов к построению ансамблей** — бустинг (англ. boosting). В нём каждая последующая модель учитывает ошибки предыдущей, а в финальном предсказании — прогнозы, построенные базовыми моделями. Представим итоговую модель, т. е. комбинацию базовых моделей, так:

$$

a_N(x)=sum^{N}_(k=1)y_kb_k(x)

$$

где a_N(x) — предсказание ансамбля, N — количество базовых моделей, b_k(x) — предсказание базовой модели, γ_k— вес модели.

Начнём с частного случая бустинга. Например, перед вами задача регрессии. Есть n объектов с признаками x и правильными ответами y. Задача — минимизировать функцию потерь MSE:

$$

MSE(y,a)=1/n \cdot sum^{n}_(i=1)(a(x_i)-y_i)^{2}->min

$$

Для удобства приравняем веса моделей к единице:

γ_k=1, для всех k=1,...,N

Получим:

$$

a_N(x)=sum^{N}_(k=1)b_k(x)

$$

Создадим ансамбль последовательных моделей.

Сперва построим базовую модель b₁, решая задачу минимизации:

$$

b_1=\arg\min  1/n \cdot sum^{n}_(i=1)(b(x_i)-y_i)^{2}

$$

Получим такой ансамбль:

```python
a_1(x)=b_1(x)
```

**Запишем остаток (англ. residual)** — разность между предсказанием на первом шаге и правильными ответами:

```python
e_(1,i)=y_i-b_1(x_i)
```

На втором шаге модель строим уже так:

$$

b_2=\arg\min  1/n \cdot sum^{n}_(i=1)(b(x_i)-e_(1,i))^{2}

$$

Ансамбль примет такой вид:

$$

a_2(x)=sum^{2}_(k=1)b_k(x)=b_1(x)+b_2(x)

$$

Вычислим остаток для каждого объекта i:

$$

e_(2,i)=y_i-a_2(x_i)=y_i-sum^{2}_(k=1)b_k(x_i)

$$

На каждом следующем шаге алгоритм минимизирует ошибку ансамбля на предыдущем.

Обобщим формулы. На шаге N-1 остаток вычислим так:

```python
e_(N-1,i)=y_i-a_(N-1)(x_i)
```

Сам ансамбль представим как сумму накопленных к этому шагу предсказаний базовых моделей:

$$

a_(N-1)(x)=sum^{N-1}_(k=1)b_k(x)

$$

Тогда на N-м шаге алгоритм подберёт модель с учётом ошибки ансамбля на шаге N-1:

$$

b_N(x)=\arg\min  1/n \cdot sum^{n}_(i=1)(b(x_i)-e_(N-1,i))^{2}

$$

Бусины - последовательное построение ансамбля моделей через улучшение предсказания на каждом шаге.

Что прогнозирует базовая модель на каждом шаге бустинга?

- Остатки на предыдущем шаге N-1.

Всё так. Мы прогнозируем остатки ансамбля с прошлого шага, минимизируя функцию ошибки.

Что такое остатки на шаге N?

- Разница между ансамблем на текущем шаге N и фактическими ответами

## Градиентный бустинг

Если объединить бустинг и градиентный спуск, получим градиентный бустинг!

Каждая базовая модель в бустинге старается «сдвинуть» предсказания прошлого шага в сторону правильных ответов. Так минимизируют функцию потерь. Градиентный спуск помогает делать это эффективнее.

Мы по-прежнему будем минимизировать функцию потерь. Но аргументом, по которому идёт спуск, станут ответы модели! Это и есть градиентный бустинг (англ. gradient boosting).

**К примеру, наша функция потерь** — L(y, a), у которой есть производная. Повторим формулу ансамбля:

```python
a_N(x)=a_(N-1)(x)+y_N*b_N(x)
```

На каждом шаге подберём ответы, которые минимизируют функцию:

```python
L(y,a(x))->min
```

Минимизируем функцию градиентным спуском. Для этого на каждом шаге вычислим антиградиент функции потерь по предсказанию gN:

$$

h_N(x)=-\nablaL(y,a_(N-1)(x)+a)

$$

Чтобы сдвинуть предсказания в нужную сторону, следующая базовая модель учится предсказывать gN:

$$

b_N(x)=\arg\min  1/n \cdot sum^{N}_(i=1)(b(x_i)-g_N(x_i))^{2}

$$

Вес при bN получаем из задачи минимизации, перебирая разные числа:

γ_N+arg min L(y,a_(N-1)(x)+γb_N(x))

Именно коэффициент при базовой модели помогает настроить ансамбль так, чтобы получить наиболее точное предсказание.

Градиентный бустинг годится для разных функций потерь, у которых есть производные. Например, среднеквадратичной в задаче регрессии или логарифмической в задаче бинарной классификации.

Что такое градиентный бустинг?

- Градиентный спуск в функциональном пространстве.

**Целевой признак базовых моделей в градиентном бустинге** — это:

- Антиградиент функции потерь.

## Регуляризация градиентного бустинга

Уменьшить переобучение градиентного бустинга поможет регуляризация.

Если в линейной регрессии снижали веса, то регуляризация для градиентного бустинга — это:

1 уменьшение размера шага;

2 настройка параметров деревьев;

3 рандомизация подвыборок у базовых моделей bᵢ.

Уменьшим размер шага. Повторим формулу расчёта предсказания на шаге N:

```python
a_N(x)=a_(N-1)(x)+γ_N*b_N(x)
```

Если алгоритм делает слишком большие шаги, он быстро запоминает тренировочную выборку, и модель переобучается.

Введём коэффициент η, который отвечает за скорость обучения (англ. learning rate). Он уменьшит размер шага:

```python
a_N(x)=a_(N-1)(x)+η*γ_N*b_N(x)
```

Значение этого коэффициента подбирается экспериментально в диапазоне от 0 до 1. Чем меньше η, тем меньше шаг в сторону антиградиента и выше точность ансамбля. Но если значение η слишком низкое, обучение будет идти медленно.

**Второй способ регуляризации градиентного бустинга** — настройка параметров деревьев. Вы можете ограничить глубину дерева или число объектов в каждом узле, попробовать их разные значения и посмотреть, как это повлияло на результат. Например, для каждого дерева введём ограничение на его глубину — 2. На каждом шаге бустинга нам не придётся создавать сложное дерево, которое точно подстраивается под все остатки. А модель не будет сильно переобучаться.

**Третий способ регуляризации** — работа с подвыборками. Алгоритм работает не со всей выборкой, а только с подвыборками. Такая версия алгоритма напоминает SGD и называется стохастическим градиентным бустингом (англ. stochastic gradient boosting).

Чем выше скорость обучения, тем выше вероятность переобучения.

В чём случайность стохастического градиентного бустинга?

- Модели обучаются на случайных подвыборках.

## Библиотеки для градиентного бустинга

На этом этапе вам пригодятся следующие библиотеки для градиентного бустинга: XGBoost, LightGBM и CatBoost.

- XGBoost (от англ. extreme gradient boosting; «экстремальный градиентный бустинг») — популярная на платформе Kaggle библиотека градиентного бустинга. Открытое программное обеспечение. Вышло в 2014 году.

- LightGBM (от англ. light gradient boosting machine; «лёгкая машина градиентного бустинга»). Разработка компании Microsoft, быстро и точно обучает градиентный бустинг. Работает с категориальными признаками напрямую. Вышла в 2017 году. Сравнение с XGBoost: https://lightgbm.readthedocs.io/en/latest/Experiments.html

- CatBoost (от англ. categorical boosting; «бустинг для категориальных признаков»). Разработка Яндекса, превосходит другие алгоритмы по метрикам качества. Применяет различные техники кодирования категориальных признаков (LabelEncoding, One-Hot Encoding*). Вышла в 2017 году. Сравнение с XGBoost и LightGBM: https://catboost.ai/#benchmark

Например, CatBoost работает с категориальными признаками просто: такса остаётся таксой, а стаффорд — стаффордом. Кодировать в 1 или 0 не нужно.

Сравним библиотеки по двум характеристикам:

| Библиотека | Работа с категориальными признаками | Скорость |
| --- | --- | --- |
| XGBoost | Нет | Низкая |
| LightGBM | Да | Высокая |
| CatBoost | Да | Высокая |

Разберём библиотеку CatBoost:

В категориальных признаках есть пропуски, записанные как новые значения: например, None в столбце Gender. Для CatBoost это не проблема, для библиотеки они — это отдельная категория.

Импортируем из библиотеки CatBoostClassifier (англ. «классификатор CatBoost») и создадим модель. Поскольку у нас задача классификации, укажем логистическую функцию потерь. Итераций будет 10, чтобы не ждать долго.

Когда итераций много и на каждой информация выводиться не должна, применяют аргумент verbose (англ. «подробный»).

Вы уже знакомы с некоторыми параметрами, которые могут сильно повлиять на результат обучения. Это максимальная глубина дерева depth, скорость обучения learning_rate и количество деревьев в ансамбле iterations.

Подберите такие гиперпараметры модели, чтобы получить значение AUC-ROC не меньше 0.822 — наилучшего результата этой метрики из курса «Обучение с учителем». Можете попробовать получить и больше.

Напечатайте на экране значение метрики AUC-ROC.

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from catboost import CatBoostClassifier
from sklearn.metrics import roc_auc_score

data = pd.read_csv('/datasets/travel_insurance.csv')
features_train, features_valid, target_train, target_valid = train_test_split(
    data.drop('Claim', axis=1), data.Claim, test_size=0.25, random_state=12345)
cat_features = ['Agency', 'Agency Type', 'Distribution Channel',
                'Product Name', 'Destination', 'Gender']
model = CatBoostClassifier(
    iterations=200,
    learning_rate=0.1,
    depth=6,
    loss_function='Logloss',
    eval_metric='AUC',
    random_seed=12345
)
model.fit(features_train, target_train, cat_features=cat_features, verbose=10)
probabilities_valid = model.predict_proba(features_valid)
probabilities_one_valid = probabilities_valid[:, 1]
print(roc_auc_score(target_valid, probabilities_one_valid))
```
