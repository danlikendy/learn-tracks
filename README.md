# Learn Tracks

Открытый репозиторий для закрепления уже изученных материалов. Первая специальность — Data Science.

Сайт: [https://danlikendy.github.io/learn-tracks/](https://danlikendy.github.io/learn-tracks/)

Исходные заметки не переписываются. Формулы набраны в LaTeX, код приведён к одному стилю (`X`, `y`, `y_pred`, `model_lr`, `clf`, `RANDOM_STATE = 42`).

## Структура

- `content/` — треки, темы, исходные txt, markdown, карточки
- `app/` — GitHub Pages: теория и практика, список и карточки, прогресс повторений, кабинет, тема, уведомления
- `.cursor/rules/` — правила контента и обозначений

## Локально

```bash
cd app
npm install
npm run dev
```

Откройте `http://localhost:5173/learn-tracks/`.
